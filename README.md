# Palm Payment — India

An independent fintech concept exploring **palm-based biometric payments integrated with India's UPI ecosystem**.

The idea is simple: users register their palm once, then make eligible payments at participating merchants by scanning their hand instead of taking out their phone and scanning a QR code.

This project proposes a potential **PhonePe × Palm Payment** partnership, using existing UPI infrastructure while adding palm authentication as a new payment interface.

### Key Features
- 🖐️ Palm-based biometric authentication
- 🇮🇳 Designed around India's UPI ecosystem
- 📱 Phone-free payment experience
- 🔐 Privacy and liveness-focused architecture
- 🏪 Designed for high-frequency environments such as campuses, malls and airports
- 🚀 Proposed 90-day pilot with 50–100 terminals

This is an **independent concept and is not affiliated with or endorsed by PhonePe**.
